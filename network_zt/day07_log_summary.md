# 정산 포털 정책 로그 점검 결과
## 결론
-정책 결정과 앱 응답이 어긋난 3건과 정책 로그에 기록되지 않은 요청 1건이 발견되었다. 정상 업무 요청의 과도한 차단을 줄이면서 위험 요청을 놓치지 않도록 보안 정책을 보완해야 한다.
## 근거
-정책 로그와 앱 접근 로그를 대조한 결과, 집행 누락 1건과 과집행 2건이 확인되었다.
-요청 201은 정책 로그에는 없지만 앱 접근 로그에서 200으로 처리되었다. 실제 정책 검사 우회인지 로그 누락인지는 추가 확인이 필요하다.
-현재 규칙은 오탐 6건·미탐 0건이며, 조정안 A는 오탐 0건·미탐 1건이다. A안에서는 해외에서 49건을 조회한 요청 11번이 거부되지 않고 추가확인으로 처리된다.
## 권고
-대량 조회 기준을 50건으로 높이는 A안을 검토하되, 해외에서 49건을 조회하는 위험 요청을 탐지할 추가 기준을 마련하고 오탐·미탐을 지속적으로 점검한다.
