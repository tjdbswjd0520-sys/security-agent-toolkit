# 2026-10-20 (화)

지속 검증 : 접속하는 동안에도 계속 다시 확인하는 것.
유지 시간 : 세션을 유지하는 시간.
세션 만료 : 유지 시간이 지나 허용이 끝나 다시 로그인하는 것
재인증 : re-authentication. 본인 확인을 다시 하는 것.
회수 : revoke. 허용을 중간에 취소하고 세션을 끝내는 것.
쿠키 : 사이트가 내 브라우저에 저장하게 한 짧은 문자열(이름=값) #괄호가 뭔 소린지 모르겠는데...
```
구글 ai개요가 제시해 준 예시
만약 로그인 정보나 다크모드 설정을 저장한다면, 브라우저에는 다음과 같은 형태로 쿠키가 기록됩니다.
• username=hong123
	• 이름: username (사용자 아이디라는 뜻)
	• 값: hong123 (실제 아이디는 hong123이라는 뜻)
• theme=dark
	• 이름: theme (화면 스타일이라는 뜻)
	• 값: dark (어두운 화면을 쓴다는 뜻)
• popup_close=yes
	• 이름: popup_close (오늘 하루 팝업창을 닫았는지 여부)
	• 값: yes (닫았으니 다시 보여주지 말라는 뜻)
웹사이트는 나중에 내 브라우저에서 이 쿠키를 읽을 때, "이름이 'theme'인 항목의 '값'이 뭐지? 아, 'dark'구나! 그럼 화면을 검은색으로 보여줘야겠다" 하고 인식하게 됩니다.
```
접속 중 상황이 바뀌면 유지, 재인증, 회수(종료) 중 하나를 고른다.
