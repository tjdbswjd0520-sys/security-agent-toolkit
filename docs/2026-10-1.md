예외처리(try, except, else, finally)
try : 가장 먼저 실행. 일단 실행. 구문 실행 중 except에 해당하는 에러가 발생하면 나머지 내용은 실행되지 않고 그 에러가 있는 except 구문이 진행된다.
except: try 구문 실행 중 해당 에러가 발생하면 실행되는 구문. 끝까지 실행되고 나면(return이 있어도) finally구문이 실행된다. 한 except 당 하나의 에러를 지정할 수 있으며(except "에러명"), except 구문은 여러 개 쓸 수 있다. switch-case의 case구문 느낌인 듯.
else: try구문을 마지막까지 실행했으나 except에 해당하는 에러가 발생하지 않았을 때 실행되는 구문. 하나의 try이 당 하나의 else만 쓸 수 있다. 마지막 코드까지 실행되면(return이 있어도) finally구문이 실행된다.
finally: try구문 안에, 실행되는 except구문이나 else구문안에 return이 있어도 "마지막에 항상, 무조건 실행되는 코드".(return 함수는 현재 실행중인 함수를 종료시키고 값을 반환시키는 함수지, 프로그램 자체를 종료시키는 함수는 아니기 때문.) try구문 실행 중 except에 없는 예외가 발생하면 else를 건너뛰고 finally가 실행된다.
#finally가 끝나도록 예외가 해결되지 못하면 상위 코드로 예외를 전달하고 그래도 해결하지 못하면 프로그램은 멈춘다.
#예외(exception): 문법적으로 옳지만 프로그램 "실행 중 특정 상황"에서 문제가 발생하는 경우.
#에러(Error): 프로그램 "실행"에 문제가 생기는 경우. 코드 실행시(혹은 직전) 발생.
