\#수업 내용

클라우드 : 업체의 서버를 인터넷으로 빌려 쓰는 것.

\-IaaS: 서버, 저장소, 네트워크를 빌리고 나머지는 회사가 직접 관리.

\-PaaS : 운영체제와 실행환경까지 업체가 관리하고 코드와 데이터만 맡는 형태. 방화벽 규칙은 일부만 걸 수 있음. 대표적으로 vercel이 있다.

\-SaaS : 완성된 서비스를 받아 쓰며 회사는 계정, 권한, 데이터만 관리.

방화벽 규칙은 I>P>S 순으로 회사가 걸 수 있는 범위가 좁아진다.(전체 > 일부 > X)

운영체제를 누구 관리하는가에 따라 서비스 유형이 갈린다.

서비스마다 접속 흔적에서 먼저 볼 기록이 달라진다.(볼 수 있느냐 없느냐도 갈린다.)

외부 PC에서 SaaS로 접속할 때는 방화벽을 지나지 않아 로그가 남지 않는다.

가시성: 보안팀이 볼 수 있는 정도. 방화벽로그가 남는가. 낮으면 로그인 기록을 직접 확인해야 함.

SaaS 로그인 기록\&방화벽 로그를 시각으로 짝짓는다. => 짝이 없는 기록이 방화벽을 지나지 않은 기록.



'''#수업 자료에서 긁어온 것

|---|---|---|

| IaaS | 운영체제 · 보안 설정 · 코드 · 데이터 | 걸 수 있다 |

| PaaS | 코드 · 데이터 | 업체가 정한 범위 안에서만 걸 수 있다 |

| SaaS | 계정 · 권한 · 데이터 | 걸 자리가 없다 |
