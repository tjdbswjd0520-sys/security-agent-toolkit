## 오늘 새로 쓴 명령
vim

## vim 으로 한 것
입력 모드로 들어가는 키: i
일반 모드로 돌아오는 키: esc
저장하고 나가는 명령: wq
저장 없이 나가는 명령: q!
지운 것을 되돌리는 키: u

일반모드에서 gg : 파일 첫 글자 앞으로 커서 이동
일반모드에서 %s/본문단어/바꿀단어/g : 바꿔준다.
일반모드에서 /단어 : 커서를 본문에서 처음 해당 단어가 등장한 곳으로 커서 이동.
일반모드에서 yy, p : 줄 복사, 붙여넣기
일반모드에서 dd : 줄 지우기
