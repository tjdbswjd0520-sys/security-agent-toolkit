PDP : 정책 결정 지점. 리소스 접근 시 허용/거부 여부를 판단.
PEP : 정책 시행 지점. PDP의 판단을 실행.
===
nginx : 엔진엑스. 웹 페이지 파일을 브라우저에 보내는 웹 서버 프로그램.
Docker : 도커. 애플리케이션을 컨테이너로 패키징해 쉽고 빠르게 배포하고 실행할 수 있게 해주는 오픈소스 컨테이너 가상화 플랫폼.
venv : 파이썬 라이브러리로 나눔 <<<>>> docker : 프로그램, 라이브러리, 설정/파일 전체
같은 도커 이미지로 컨테이너 여러 개를 키면 : 접속 분산, 고장 대비, 환경 분리
