\--

packet : 데이터 단위. 수신지 주소가 들어 있다.

ping : 명령어. 에코 요청을  4번 보낸다. 응답(서버-클라이언트 연결 여부), 시간(왕복 시간), TTL(편도 결과 남은 TTL), 손실(패킷손실이 일어난 데이터의 비율), 평균(왕복 시간 평균?)을 반환. 보안상의 이유로 에코 응답을 반환하지 않는 서버도 있음. # ICMP 프로토콜에서 사용되는 듯?

DNS : URL > IP

TTL :중간에 지나칠 수 있는 라우터(또는 공유기)의 수. 기본값은 OS가 지정. 하나 지날 때마다 1씩 감소하며 TTL이 0인 패킷은 폐기(패킷손실)된다.

라우터: WAN 내부에서 데이터 전달.

공유기: 라우터 + 여러 기기가 하나의 인터넷 주소 공유.

default gateway : 다른 망(다른 LAN?)으로 가는 패킷을 받아 넘기는 장비. 보통은 공유기.

8.8.8.8 : 구글 DNS.

OSI 7Layer : 물리, 데이터링크, 네트워크, 전송, 세션, 표현, 응용

스위치 :  LAN내부에서 데이터 전달

이더넷 : MAC 주소. 2계층

ARP : MAC 주소 묻는 프로토콜.

\---

SYN : 연결 시작 요청 플래그

ACK : 패킷 수신 확인 플래그

캡처 필터 : 캡처 시작 전에 조건을 걸어두는 것. # tcp port 80

HTTP : 포트 80. 암호화없이 웹 요청과 응답을 주고 받는다.

&#x20;curl : 웹 요청을 보내는 명령어.

HTTPS : 포트 443. 암호화해서 웹 요청과 응답을 주고 받는다.

TLS : HTTPS의 암호화 방식.

상태코드 : 서버가 답의 가장 앞에 붙이는 숫자. #200:성공, 404:없음, ...
